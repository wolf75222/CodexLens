# Codex Lens 0.42.5

## Changed

- Simplify the session picker: keep refresh as a labelled icon beside search, group Close and Open in the native dialog footer, and remove the repeated explanatory footer. Preserve Return, Escape, row selection and the existing loading/cancellation flow.

## Installation and compatibility

Download `CodexLens-0.42.5-arm64.dmg` and drag Codex Lens to Applications. The app ZIP is an alternative; the symbols ZIP, checksums and metadata accompany the download.

See the [documentation for this version](https://github.com/wolf75222/CodexLens/blob/v0.42.5/README.md#requirements-and-boundaries) for platform, Codex adapter and signing limits, and the [release process](https://github.com/wolf75222/CodexLens/blob/v0.42.5/docs/RELEASING.md) for validation details. A changelog entry does not establish interactive or live-service qualification.
