# Codex Lens 0.42.8

## Changed

- Choose session chart marks from count density: bars for dense intervals, discrete stems for sparse occurrences and steps for cumulative totals, starting at zero. Make click and drag select a period, replace the full-chart focus rectangle with the selected cursor, and preserve keyboard navigation and the linked values table.

## Installation and compatibility

Download `CodexLens-0.42.8-arm64.dmg` and drag Codex Lens to Applications. The app ZIP is an alternative; the symbols ZIP, checksums and metadata accompany the download.

See the [documentation for this version](https://github.com/wolf75222/CodexLens/blob/v0.42.8/README.md#requirements-and-boundaries) for platform, Codex adapter and signing limits, and the [release process](https://github.com/wolf75222/CodexLens/blob/v0.42.8/docs/RELEASING.md) for validation details. A changelog entry does not establish interactive or live-service qualification.
