# Codex Lens 0.43.2

Changed files now appear in a native tree grouped by worktree and folder, beside the selected diff. Resize or hide the right pane, filter files, navigate with arrow keys, and reveal the selected file. Compact windows place the tree below the reading area.

Expansion, viewport and selection stay local to each window and survive live publication. Back/Forward restores the file filter and tree state. Recorded paths remain distinct from current files; viewing the tree does not read Git or execute recorded actions.

Requires macOS 14 or later on Apple Silicon. Community builds use ad hoc signing and are not Apple-notarized.
