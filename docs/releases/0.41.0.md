# Codex Lens 0.41.0

First public community release of the native macOS session inspector.

## Explore a session

Open an existing session by ID or Codex deep link, inspect its agents, calls, environments, resources and changes, and follow available new events. Recorded file versions and current worktree content remain separate. The sidebar investigation chat uses the installed Codex and its ChatGPT connection; no separate API key is required for that mode.

## Fixes included in this release

- Reuse one pending local Codex connection rather than launching duplicate subprocesses.
- Prevent delayed connection launches from surviving shutdown or publishing stale account state.
- Preserve a noncancelled connection waiter when another waiter is cancelled, while keeping shutdown able to close the owned child.
- Simplify first-use screens, session selection and empty states.
- Update both icon variants with a thicker, continuously joined magnifying glass.

## Download and install

Open `CodexLens-0.41.0-arm64.dmg` and drag Codex Lens to Applications. The application ZIP is an alternative. The symbols ZIP contains matching dSYMs for diagnostics. `CHECKSUMS.sha256` and `release-metadata.json` identify the artifacts, source revision and binary UUID.

## Current qualification

Apple Silicon download; macOS 14 deployment target. The native app is built with Xcode 26.6/macOS 26 SDK, with Liquid Glass restricted to available system controls. The Codex App Server adapter is qualified for **0.159.2**. Community CI uses ad hoc signing and these artifacts are not Developer ID notarized. Use normal macOS Privacy & Security controls for first launch; do not disable Gatekeeper.

Offline Swift, Python, native component and installer checks run before publication. Live account/inference tests are opt-in and are not run by public CI. No Intel/macOS 14 interactive-runtime, VoiceOver or fresh performance qualification is implied.
