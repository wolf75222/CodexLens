# Codex Lens 0.43.4

Stable community release for Apple Silicon on macOS 14 or later. This release includes all changes since the previous public release, 0.43.0; 0.43.1–0.43.3 were local development builds.

## Highlights

- Loading bars appear immediately and show the current phase, measured work and remaining counts for session opening, linking, presentation, timeline preparation, conversation export and file search. Unknown totals remain indeterminate; counters describe the current phase, without estimating total duration. Reduce Motion and cancellation remain supported, and repeated index work is reduced.
- Changed files appear in a native tree grouped by worktree and folder beside the selected recorded diff. Resize or hide the pane, filter paths, navigate with arrow keys, copy a recorded path, open a current file or reveal the selection. Compact windows place the tree below the reading area. Each window retains its expansion, viewport, selection and filter through refresh and Back/Forward. The tree uses recorded change projections; identical paths in different worktrees remain distinct.
- Choose reasoning effort beside the model in the chat composer or AI settings. Available levels and defaults come from the installed Codex catalogue. Lens remembers choices per model and freezes each request's effort before sending. Unavailable saved levels require an explicit new choice or clearing the preference; missing capability metadata is shown without inventing levels or rewriting Codex settings.
- Open the signed native update flow from the toolbar's download-arrow button or **Settings → General → Update app…**. It shows the available stable version and download/install progress, then offers installation and relaunch in place while preserving Lens data. **Show update…** brings an existing update window forward. Repeated clicks preserve its version and progress; newer local builds are not downgraded to an older public release.

## Validation and installation

Loading, tree and effort checks use anonymous fixtures. Their captures are offscreen AppKit renders; tree and effort captures use replacement QA entry points. These checks do not establish physical input, VoiceOver, the production compositor, live authenticated inference or performance. Signed-feed and package checks are separate from an end-to-end upgrade using an older installed app. See the [feature catalogue](https://github.com/wolf75222/CodexLens/blob/v0.43.4/docs/FEATURES.md) and [update verification limits](https://github.com/wolf75222/CodexLens/blob/v0.43.4/docs/UPDATES.md).

Download `CodexLens-0.43.4-arm64.dmg` and drag **Codex Lens** to **Applications**. Community binaries are ad hoc signed and are not Apple-notarized. macOS may require first-launch approval in Privacy & Security; do not disable Gatekeeper. Sparkle signatures authenticate updates separately from Apple notarization.
