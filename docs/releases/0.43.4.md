# Codex Lens 0.43.4

Use the download-arrow button in the toolbar, or **Update app…** in General settings, to open the native update flow. It checks the latest stable GitHub release, shows the available version and download/install progress, and offers installation and relaunch. Sparkle replaces the application at the same location and preserves Lens data.

When an update window is already open, the button becomes **Show update…** and returns to that window. Repeated clicks use current updater state rather than creating a second download or losing the available-version display.

Updates use the existing signed appcast and signed archive. A newer local build is not downgraded to an older public release. The button reports that the app is current until a newer compatible stable release is published.
