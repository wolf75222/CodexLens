# Codex Lens 0.43.1

Loading now uses thin native bars with the current phase, measured work and remaining counts. Opening steps expand on demand. Session linking, presentation/timeline preparation, conversation export and file search expose useful progress without estimating unknown totals or remaining duration.

The update also reuses agent indexes, avoids rescanning old descendant owners and skips progress accounting without a subscriber. Cancelled diff parsing stops its worker. These changes preserve recorded sources, window navigation and frozen conversation exports.

Requires macOS 14 or later on Apple Silicon. Drag Codex Lens to Applications in the DMG. The community build uses ad hoc code signing and is not Apple-notarized. Update feed and archives use the configured Sparkle signature.
