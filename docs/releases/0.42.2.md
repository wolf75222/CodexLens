# Codex Lens 0.42.2

Prepared development build; not published as a GitHub release. Its changes are included in 0.43.0.

## Added

- Agent information in the existing inspector and context menu: recorded role, available descriptions, model/effort configuration, requested spawn settings and links to original tasks/instructions. Missing fields stay unavailable; request settings require an explicit child link.

## Changed

- Include agent attributes in search and version the compact header/event caches for their new fields, while keeping prompt and instruction bodies in original sources.
- Refresh agent information when only the Codex thread database changes, without rereading unchanged journal headers.

## Installation and compatibility

Download `CodexLens-0.42.2-arm64.dmg` and drag Codex Lens to Applications. The app ZIP is an alternative; the symbols ZIP, checksums and metadata accompany the download.

See the [documentation for this version](https://github.com/wolf75222/CodexLens/blob/v0.43.0/README.md#requirements-and-boundaries) for platform, Codex adapter and signing limits, and the [release process](https://github.com/wolf75222/CodexLens/blob/v0.43.0/docs/RELEASING.md) for validation details. A changelog entry does not establish interactive or live-service qualification.
