# Codex Lens 0.42.6

Prepared development build; not published as a GitHub release. Its changes are included in 0.43.0.

## Changed

- Connect session loading indicators to measured work: catalog files processed, current journal byte extent and events organized. Show named stages for discovery, index restoration, linking and saving when totals are unknown. Refresh keeps existing rows available; cancellation and shared-reader isolation remain intact. Progress describes the current stage, not an estimated whole-operation percentage.

## Installation and compatibility

Download `CodexLens-0.42.6-arm64.dmg` and drag Codex Lens to Applications. The app ZIP is an alternative; the symbols ZIP, checksums and metadata accompany the download.

See the [documentation for this version](https://github.com/wolf75222/CodexLens/blob/v0.43.0/README.md#requirements-and-boundaries) for platform, Codex adapter and signing limits, and the [release process](https://github.com/wolf75222/CodexLens/blob/v0.43.0/docs/RELEASING.md) for validation details. A changelog entry does not establish interactive or live-service qualification.
