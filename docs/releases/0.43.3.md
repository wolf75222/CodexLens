# Codex Lens 0.43.3

The sidebar chat shows reasoning effort next to the model. Choose an available level in the compact menu, or use the model’s advertised default. The same control is available in AI settings.

Available levels come from the installed Codex model catalogue. Preferences are kept per model in Lens. A request freezes its effort before sending, including follow-up messages in the same owned chat. Unavailable saved levels require a new choice rather than a silent fallback.

When Codex does not expose effort metadata, no levels are offered. This does not imply a known effective effort for legacy requests that omit the parameter. Local Codex credentials, global configuration and observed sessions are unchanged.

A saved choice that becomes unavailable can be explicitly cleared. This removes the Lens preference; when no default is reported, Codex retains its own current setting.

Local verification: 701 Swift tests with 4 opt-in tests skipped and no failures, plus 51 native checks for per-model choices, recovery, accessibility and visible controls in narrow/wide English/French panels. Native captures use anonymous metadata and offscreen AppKit rendering; they do not establish live authenticated inference, physical input or VoiceOver behavior.
