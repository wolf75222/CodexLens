# Codex Lens 0.42.9

## Changed

- Show one aggregate history progress bar across all known session journals, weighted by their byte sizes. Keep the current file counter below it, move its name to a tooltip, and show the opening stage out of four. New descendants and growing journals update the measured totals; missing bounds remain indeterminate.

## Installation and compatibility

Download `CodexLens-0.42.9-arm64.dmg` and drag Codex Lens to Applications. The app ZIP is an alternative; the symbols ZIP, checksums and metadata accompany the download.

See the [documentation for this version](https://github.com/wolf75222/CodexLens/blob/v0.42.9/README.md#requirements-and-boundaries) for platform, Codex adapter and signing limits, and the [release process](https://github.com/wolf75222/CodexLens/blob/v0.42.9/docs/RELEASING.md) for validation details. A changelog entry does not establish interactive or live-service qualification.
