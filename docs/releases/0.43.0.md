# Codex Lens 0.43.0

Stable community release for Apple Silicon on macOS 14 or later. This update includes the accumulated improvements since the previous public release, 0.41.0; 0.42.x builds were development iterations.

## Highlights

- Review changes like a PR: files grouped by worktree, selectable recorded activities, parallel worktree lanes and direct access to recorded diffs. Close marks group their operations without losing their links. Unknown dates and branch information stay unavailable.
- Read a current global Git diff for a selected worktree, including comparison from its recorded full commit. Historical traces and current files remain separate; missing commits never silently fall back to HEAD.
- Use the Codex installed on the Mac with a ChatGPT connection. The adapter qualifies exact versions 0.159.2 and 0.160.1, preserves a separate investigation chat, and rejects API authentication and unapproved tools.
- Keep the timeline, filters, selection and reading position when opening tabs, using Back or inspecting an item in another window.
- Inspect session activity charts, recorded agent information, context, compactions and communications in the existing navigation.
- Open sessions with validated metadata caching, measured aggregate history progress, a simpler picker and reliable cancellation.
- Use signed in-app updates from GitHub and a reviewed uninstall flow that preserves local data by default.

## Interface and release cleanup

New installations default to English and Dark appearance. Timeline colors remain visible across zoom, accents are consistent, event rows align, diff presentation stays in the More menu, and the changes view adapts to available width. Advanced graph information stays behind an information control.

The component fixture gallery and Development menu are Debug-only. Release packaging rejects QA identifiers, test display names and environment overrides. The downloaded app has the normal Codex Lens identity and uses the local Codex home; no fixture session is forced.

## Validation

The Release suite passed 653 tests (3 skipped) and all 117 script tests. The changes overview passed 43 native component/AX checks with 13 anonymous component bitmap captures. Source hashes remained unchanged during observation. Two small anonymous live questions with installed Codex 0.160.1 and ChatGPT completed, including a same-thread follow-up after an engine restart. These checks do not qualify every model, account, VoiceOver path or supported macOS version.

The publishing workflow requires exact-revision CI, installer checksums, bundle resources/signatures, matching symbols and signed update artifacts before publication. See the [full changelog](https://github.com/wolf75222/CodexLens/blob/v0.43.0/CHANGELOG.md) and [feature catalogue](https://github.com/wolf75222/CodexLens/blob/v0.43.0/docs/FEATURES.md).

## Install

Download `CodexLens-0.43.0-arm64.dmg` and drag **Codex Lens** to **Applications**. Replace an older copy when prompted; app data remains separate from the bundle. The app ZIP is an alternative. Checksums, source metadata and matching symbols accompany the release.

Community binaries are ad hoc signed and are not Apple-notarized. macOS may require first-launch approval in Privacy & Security. Sparkle signatures authenticate in-app updates separately and do not provide Apple notarization. Do not disable Gatekeeper.
